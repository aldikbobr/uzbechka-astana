# Бункер — концепт сайта

Концепт-сайт пейнтбольного клуба **«Бункер»** (Астана, 4 площадки).

> Репозиторий называется `uzbechka-astana`: изначально он был под ресторан «Узбечка №1». У того в Google Картах нашёлся современный сайт uzbechka1.kz, поэтому место отдали «Бункеру». Репозиторий лучше переименовать в `bunker-paintball-astana` (Settings → General → Repository name).

- Сайт: https://bunker-paintball-astana.vercel.app
- Закрыт от поисковиков (`noindex, nofollow`), в подвале помечен как концепт.
- Зачем: 1 074 оценки и 4,8 в 2ГИС, а вместо сайта — страница Taplink (astanapaintball.taplink.ws).

## Что внутри
- Прелоадер «Заряжаем маркер», плавный скролл (Lenis), сцены GSAP ScrollTrigger.
- Первый экран: нажатие в любом месте оставляет кляксу краски, на заголовок при загрузке «прилетают» три выстрела.
- Режимы: пейнтбол 10+, страйкбол 18+, лазертаг.
- Калькулятор по реальному прайсу: игра, пакет, число игроков, доп. услуги → сумма на команду и с человека, хоппер наполняется шариками. Расчёт уходит в WhatsApp.
- Экипировка, брифинг-чеклист с галочками, поводы (цитаты из отзывов), 4 площадки со статусом «открыто/закрыто», отзывы, бронь в WhatsApp, FAQ.
